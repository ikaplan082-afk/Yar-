# Street Racing Türkiye — Aşama 1

GitHub Pages uyumlu mobil HTML5 Canvas arcade yarış prototipi.

## Aşama 1 özellikleri
- Pseudo-3D yol ve gece şehir atmosferi
- Oyuncu aracı ve yumuşak takip kamerası
- İyileştirilmiş arcade sürüş fiziği: hız ataleti, motor freni, fren, yanal hız, grip ve hafif drift
- Nitro
- Trafik ve temel çarpışma
- Mobil butonlar + PC klavyesi
- Yatay ekran
- localStorage kayıt altyapısı

## Kontroller
Mobil: SOL / SAĞ / GAZ / FREN / NİTRO
PC: A/D veya ←/→, W/↑, S/↓, Space/Shift

`index.html` çalıştırma girişidir. `js/` klasöründeki modüller sonraki aşamalarda aktif sistemlere ayrıştırılacaktır.
